## 1. 滑滑轉帳（新頁面 `#/swipe`）

**入口**：帳戶頁右上「滑滑轉帳」按鈕；首頁的 ＋ 長按也能進。

**畫面**（參考 iLeo）
- 最上方：轉出帳戶下拉選單，下面一行顯示可用餘額，旁邊的眼睛按鈕可以隱藏金額，隱藏狀態會記住。
- 中央：大頭像代表轉出帳戶，上方有「拖曳頭像轉帳」提示泡泡（第一次使用才出現，之後自動隱藏）。
- 外圍：2～3 圈同心圓環，每圈平均排列其他帳戶的頭像。
  - 包含銀行、電子支付、現金、信用卡、存錢目標。轉到信用卡＝繳卡費，轉到存錢目標＝存錢。
  - 頭像下方顯示帳戶名稱。
  - 與目前轉出帳戶不同幣別的帳戶，頭像變灰但仍可拖。放開後會多出「轉入金額」欄位。
- 右上「排序」：常用優先（依過去 90 天轉帳次數）或手動排序（拖曳調整，存在 meta）。
- 右下「＋ 新增帳戶」。

**操作**
1. 按住中央頭像（Pointer Events，手機和滑鼠都適用）拖曳，頭像跟著手指移動，後面拖出一條虛線。
2. 經過可轉入的頭像時，該頭像放大並發光（吸附判定半徑 = 頭像半徑 × 1.3）。
3. 在目標上放開：頭像飛進目標並播放動畫，接著跳出金額鍵盤 Sheet（沿用現有 Keypad，可以輸入運算式），還有日期與備註。
4. 按完成就建立一筆 `transfer` 交易，並顯示「已轉 NT$500 → 數位帳戶」，提供 3 秒內「復原」。
5. 沒放在任何目標上就彈回中央。

**可調整的趣味設定**（右上齒輪）
- 外觀主題：森林綠（預設）、海洋、夕陽、夜空，各自是一組圓環漸層。
- 動畫：飛入（預設）、彈跳、彩帶、關閉（`prefers-reduced-motion` 時自動關閉）。
- 音效：開或關。用 Web Audio 合成短音，不載入音檔。
- 震動：Android 用 `navigator.vibrate`。iOS Safari 不支援，設定裡註明。
- 頭像：沿用帳戶圖示（見第 6、7 節，可上傳照片）。

> 原本的一般轉帳（記帳頁的「轉帳」分頁）保留不動。

## 2. 養成系統（新頁面 `#/pet`，首頁頂部顯示寵物小卡）

### 2.1 寵物
- **選擇**：第一次進入時選一隻，例如囤囤倉鼠（主角）、松鼠、兔子，可以命名。用我自繪的 SVG，每隻有 4 種情緒 × 4 個成長階段。
- **經驗值**（以實際交易紀錄計算，不能手動灌）
  | 行為 | XP |
  |---|---|
  | 當天有記帳（每天只算一次） | +10 |
  | 連續記帳第 7／30／100 天 | +50／+200／+500 |
  | 月底總預算沒超支 | +100 |
  | 存錢目標每存入目標金額的 10% | +30 |
  | 確認一筆待確認交易 | +2（每天上限 10） |
- **等級與階段**：蛋 → 幼年（Lv5）→ 少年（Lv15）→ 成年（Lv30）。升級門檻逐級遞增。
- **心情**：依「本月預算已用 % ÷ 本月已過天數 %」決定。
  - ≤ 0.9 開心，≤ 1.1 普通，≤ 1.3 擔心，超過 1.3 或已超支是難過。
  - 沒設預算時改看最近 3 天有沒有記帳。
- **斷記帳**：超過 3 天沒記帳，寵物會「餓」（顯示不同表情與提示）。不扣經驗值，避免挫折感。
- **互動**：點寵物會說一句話，內容依目前狀態從句庫挑。例如「這個月吃的花了 4,200，比上個月少 12% 耶」。

### 2.2 存錢目標（新資料表 `goals`）
- 欄位：名稱、目標金額、對應帳戶（可以專開一個「存錢」帳戶，也可以綁現有帳戶）、截止日（可不填）、圖示、樣式。
- **進度**：目標建立後，對應帳戶的淨轉入金額。舊錢不會被算進去，也可以選擇「把目前餘額算進去」。
- **視覺化**（可選）：存錢罐慢慢裝滿、房子一塊塊蓋起來、植物慢慢長大。
- 有截止日時，顯示「每天還要存 NT$xx」。
- 目標達成：放彩帶並頒發徽章。

### 2.3 成就徽章
大約 20 個，例如：
- 第一筆、連續 7／30／100／365 天
- 第一次月預算達標、連續 3 個月達標
- 記滿 100／1000 筆
- 第一次完成存錢目標
- 建立第一筆週期記帳
- 匯入第一次發票
- 第一次備份
- 夜貓子（凌晨記帳）
- 外幣達人（記了 5 種幣別）

做法：
- 每次開 App 時跟補跑引擎一起檢查。條件大多能從既有資料回推，所以舊資料也能補拿。
- 已解鎖的徽章存在 meta `achievements`（id → 解鎖日期）。
- 徽章頁：已解鎖的是彩色，未解鎖的是灰色剪影並顯示提示。

## 3. 月報卡

- **設定**：開關，以及「每月 N 號」（1～28，預設 1 號）。
- **觸發**：今天 ≥ 本月 N 號，而且還沒看過上個月的月報（meta `reportSeen:YYYY-MM`），開 App 時就跳出全螢幕卡片。
- **內容**（以目前帳本為準，也可以切成總帳本）
  - 上個月總支出、總收入、結餘，和前一個月比較（↑↓%）
  - **佔比最高的分類**：名稱、金額、百分比，用大字顯示
  - 前 3 名分類的長條，最大一筆消費
  - 記帳天數、預算達成狀況
  - 寵物的一句評語
- **按鈕**：「存成圖片」（用 Canvas 繪製後下載 PNG，iOS 會出現分享面板）、「看完整統計」（跳到該月統計）、「知道了」。
- 設定頁可以隨時重看任一月份的月報。
- 錯過也沒關係：如果整個月都沒開 App，下次打開時只顯示最近一期的月報。

## 4. 手機輸入不放大 + 字體大小

- **原因**：iOS Safari 的輸入框字級小於 16px 時，點進去會自動放大。
- **解法**
  1. 所有 `input`、`select`、`textarea` 字級至少 16px。這是根本解法，不會影響使用者自己雙指縮放的輔助功能。
  2. viewport 加上 `maximum-scale=1`，雙重保險，防止點輸入框時自動放大。
  3. 停用雙擊縮放（`touch-action: manipulation`）。
- **字體大小設定**：設定頁 → 外觀 → 字體大小，分小、標準、大、特大（0.9／1／1.15／1.3 倍）。
  - 全站字級改用 `rem` 加上根字級變數，選擇後立即生效並記住。
  - 輸入框依然維持至少 16px。

## 5. 信用卡顯示方式

信用卡設定新增「顯示方式」，每張卡各自設定。

| 選項 | 帳戶列表顯示 | 範例 |
|---|---|---|
| 已刷金額（預設） | −目前欠款，紅字 | −NT$12,340 |
| 可用額度 | 額度 − 欠款 | 可用 NT$87,660 |

- 帳戶頁和首頁的帳戶摘要都依照這個設定顯示。
- 卡片詳情頁維持完整資訊：欠款、已出帳、未出帳、可用額度。
- 淨資產計算不受影響，信用卡一律算負債。
- 設定頁也有「全部信用卡統一套用」的快捷切換。

## 6. 圖示系統重做

### 6.1 圖示格式（統一欄位 `icon: string`）
| 前綴 | 意義 | 範例 |
|---|---|---|
| （無） | emoji，保留相容 | `🍜` |
| `svg:` | 內建 SVG 圖示 | `svg:food-bowl` |
| `img:` | 使用者上傳的圖片（存在 `assets` 資料表） | `img:3f2a…` |
| `txt:` | 文字或縮寫 | `txt:早` |

用一個共用元件 `<CatIcon :icon :color :size>` 統一渲染。分類、帳戶、帳本、存錢目標全部共用。

### 6.2 自繪 SVG 圖示（需求 6）
- 每個預設分類（目前 41 個）提供 **3 個不同設計**的自繪 SVG，總共約 125 個。
  - 不是同一個圖換線條粗細，是 3 個不同造型。例如「午餐」有便當盒、筷子夾飯、餐盤。
  - 統一風格：24×24 網格、圓角筆畫、`currentColor` 上色，深淺色主題都適用。
- 另外做一組「囤囤角色風」：主要大類約 15 個，帶臉的可愛版本。
- 圖示選擇器分頁：
  - 「推薦」：依目前分類名稱推薦相關 SVG
  - 「全部圖示」：可搜尋，每個圖示有中文關鍵字
  - 「emoji」
  - 「文字」
  - 「上傳」
- 開工時第一步先做一個**圖示預覽頁**，給你挑過、有不喜歡的先換掉，再接進 App。

### 6.3 使用者上傳圖片
- 從相簿選圖 → 正方形裁切（拖曳、縮放）→ 壓縮成 128×128 WebP（約 5～10 KB）→ 存進 `assets` 資料表。
- JSON 備份會一併包含圖片（base64）。

## 7. 分類管理自定義

- **任意顏色**：原本的色點保留當快選，最後一格是色盤（`<input type="color">`）。
- **拖曳排序**：長按拖曳，用 `vue-draggable-plus`（SortableJS，支援觸控）。
  - 大類可以互相排序。
  - 子分類可以拖到另一個大類底下（換大類）。
  - 也可以把子分類拖出來變成大類。
  - 有交易的大類不能直接變成子分類，會提示先搬移。
- **圖示**：用第 6 節的新選擇器，支援上傳圖片和文字。
- **文字圖示**：1～3 個字，自動依字數調整字級，背景用分類顏色。
- 帳戶頁也套用同樣的拖曳排序與圖示選擇器。

## 8. 統計頁補強（依截圖）

- **月統計**加「收支日曆」：週日到週六排列，每格顯示當日金額。
  - 金額越高格子底色越深（依當月分位數分 3 級），今天用主題色標示。
  - 點日期跳到那天的明細。
  - 支出和收入切換跟著頁面頂端的切換走。
- **每日對比**：當月每天金額的折線圖，疊一條上個月同日的淡色線。
- 頂部顯示筆數、日均、總額，以及對面類別（收入／支出）和結餘的小標籤，排版照截圖。
- **總帳本**：帳本選單加「總帳本」選項，合併所有帳本統計，各帳本幣別換算成主要幣別。

## 9. 資料庫變更（Dexie schema v2）

```ts
goals:   'id, bookId, accountId, archived'     // 存錢目標
assets:  'id'                                  // 使用者上傳的圖片 {id, mime, data: Blob}
```
- 新增欄位：
  - `Account.credit.display: 'spent' | 'available'`
  - `Account.avatar?`（滑滑轉帳的頭像，沒設定時用 icon）
- 寵物、成就、月報已讀、滑滑轉帳設定、字體大小都存在 `meta`。
- 升級程式：既有資料不動。舊的 emoji 圖示照常顯示；`credit.display` 預設 `'spent'`。
- 備份格式 `schemaVersion: 2`，可以讀 v1 的備份。

## 10. 實作順序

1. 第 4 節（輸入放大、字體大小）、第 5 節（信用卡顯示）：小改動，先上
2. 第 6 節：圖示系統、圖示預覽頁 → **你挑完圖示後**再接進 App
3. 第 7 節：分類自定義（拖曳、色盤、上傳、文字圖示）
4. 第 8 節：統計日曆、每日對比、總帳本
5. 第 1 節：滑滑轉帳
6. 第 2 節：養成（寵物 → 存錢目標 → 徽章）
7. 第 3 節：月報卡
8. 測試、部署

每做完一段就 commit 並部署一次，讓你可以邊用邊回饋。
